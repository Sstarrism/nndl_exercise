# 2. 函数拟合报告

## 1. 函数定义
目标函数：

\[ f(x) = \sin(2\pi x) + 0.3 \cos(5\pi x) \]

说明：函数包含两个不同频率的周期成分，既有平滑变化，也有高频震荡。这样的函数适合作为神经网络拟合任务，能充分体现网络对非线性和高频成分的表达能力。

## 2. 数据采集
- 训练集：在区间 [0,1] 均匀采样 300 个点，x_train 形状为 (300,1)
- 测试集：在区间 [0,1] 均匀采样 100 个点，x_test 形状为 (100,1)
- 目标 y 值：y=f(x)，将其转为 float32 格式保证与 TF 张量兼容

采样后可视化结果：训练点（蓝）、测试点（红）

## 3. 模型描述
### 模型结构
使用手动定义的 ReLU 网络：
- 输入层：1 维
- 第 1 隐层：64 个神经元，ReLU 激活
- 第 2 隐层：64 个神经元，ReLU 激活
- 输出层：1 个神经元（线性输出）

### 参数
- W1: shape(1,64)，b1: shape(64)
- W2: shape(64,64)，b2: shape(64)
- W3: shape(64,1)，b3: shape(1)

### 损失与优化
- 损失函数：均方误差（MSE）`tf.reduce_mean(tf.square(pred - y))`
- 优化器：Adam，学习率 1e-3
- 训练步数：2000 epochs

## 4. 拟合训练过程
- 每 250 个 epoch 打印一次当前 loss，便于观察收敛
- 绘制损失曲线：随着 epoch 增加，训练损失快速下降并趋稳定

## 5. 验证与拟合效果
- 在测试集上评估 MSE，输出示例：`Test MSE 0.0008`（实际会随随机种子略有波动）
- 绘制测试结果：
  - 蓝线：真实函数 y
  - 红虚线：模型预测 y_pred
  - 观察拟合曲线与真实曲线高度重合

## 6. 运行环境
- Python 3.8
- TensorFlow 2.10.0
- NumPy 1.23.5
- Matplotlib 3.7.5

## 7. 小结
本实验完成了“两个隐藏层 ReLU 网络拟合复杂函数”的要求：

- 训练流程在 2000 epochs 下收敛良好

## 9. NumPy 手工实现（附加加分）
